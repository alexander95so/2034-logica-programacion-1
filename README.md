# Análisis de Datos de Tiendas

## Descripción del Proyecto

Este proyecto tiene como objetivo analizar datos de ventas de diferentes tiendas con el fin de generar información útil para la toma de decisiones comerciales. A través del análisis de ingresos, categorías de productos, reseñas de clientes y costos de envío, se busca identificar cuál tienda ofrece mejores condiciones para que el Sr. João venda sus productos.

El análisis incluye la exploración de datos, la visualización mediante gráficos y la elaboración de una recomendación basada en evidencia.

## Objetivos

- Analizar el desempeño de diferentes tiendas a partir de sus datos de ventas.
- Identificar patrones de consumo y comportamiento de los clientes.
- Visualizar los resultados mediante gráficos claros y comprensibles.
- Generar una recomendación final basada en los resultados obtenidos.

## Análisis de Datos

Durante el desarrollo del proyecto se evaluaron diferentes aspectos de las tiendas, incluyendo:

- Ingresos totales generados por cada tienda.
- Categorías de productos más vendidas.
- Productos con mayor número de ventas.
- Calificaciones y reseñas de los clientes.
- Promedio de costos o tiempos de envío.

Este análisis permite comparar el desempeño de cada tienda y evaluar su potencial comercial.

## Visualización de Datos

Para facilitar la interpretación de los resultados, se utilizaron diferentes tipos de gráficos, entre ellos:

- **Gráficos de barras** para comparar ventas e ingresos.

Estas visualizaciones ayudan a comprender de forma más clara los patrones presentes en los datos.
